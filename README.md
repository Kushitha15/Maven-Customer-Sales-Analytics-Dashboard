# Maven-Customer-Sales-Analytics-Dashboard
An interactive MS Excel dashboard designed to analyze customer behavior, product performance, and sales trends using the Maven retail dataset. This project focuses on transforming raw transactional data into meaningful insights to support business decision-making. The dashboard enables users to monitor key KPIs, identify sales patterns, and evaluate performance across regions, products, and customers.

**Tools & Technologies**
Microsoft Excel – Main platform for dashboard creation
Power Query – Data cleaning, transformation, and ETL process
Pivot Tables & Pivot Charts – Data aggregation and analysis
Excel Formulas – KPI calculations (Sales, Profit, Orders)
Data Modeling – Creating relationships between multiple tables
Slicers & Timeline – Interactive filtering and dynamic reporting

Data Source
Maven Analytics Retail Dataset – Project work provided by trainer

**Business Problem**
Retail businesses often struggle to analyze large volumes of transactional data to understand customer purchasing behavior, product performance, and regional sales trends.

**Goal of the Dashboard**
Track key performance metrics (Total Sales, Profit, Orders)
Identify top-performing products and regions
Analyze customer contribution and buying patterns
Monitor sales trends over time
Evaluate returns and product performance

Project Impact
This dashboard helps businesses gain clear visibility into sales performance, customer insights, and product trends, enabling data-driven decision-making and improved business strategies.
